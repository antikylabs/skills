# Run states

Compare these four interface states:

| State | Primary content | Action |
| --- | --- | --- |
| Ready | Prompt summary | Run |
| Running | Live event stream and progress | Stop |
| Needs approval | Requested command and risk | Approve or deny |
| Complete | Result summary and changed files | Review |

Use the product surface: Inter, a deep navy background, pale text, blue accents, and rounded cards.
Desktop shows the four states side by side. Mobile stacks them in workflow order.
