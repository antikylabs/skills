# Notice

This skill carries work from two MIT-licensed sources. Both contributed substance, not just
inspiration.

## ponytail

[DietrichGebert/ponytail](https://github.com/DietrichGebert/ponytail) — *"Makes your AI agent think
like the laziest senior dev in the room. The best code is the code you never wrote."*

[reference/ladder.md](reference/ladder.md) carries its ladder — the rungs you stop at before writing
code — its inverse list of what laziness does not apply to, and the `ponytail:` comment convention
for marking a deliberate simplification with its ceiling.

## mattpocock/skills

[mattpocock/skills](https://github.com/mattpocock/skills) — *"Skills for Real Engineers."*

[reference/talk-it-out.md](reference/talk-it-out.md) is built on the grilling mechanism from
`skills/productivity/grilling`: the design tree, rounds, the frontier of decisions whose
prerequisites are settled, and the rule that finding facts is the agent's job rather than the
user's.

The command structure here — separate named jobs rather than one "engineering" skill — follows the
shape of that repository's `skills/engineering/`.

## GOOD_ENGINEERING_H.md

[reference/GOOD_ENGINEERING_H.md](reference/GOOD_ENGINEERING_H.md) is Antiky Labs' own engineering
principles. It is human-owned — the `_H` suffix travels with it — and this copy is the source of
truth, so the skill works in a repository that does not carry the file.
