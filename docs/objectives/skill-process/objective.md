## What we want

> Owner's words: "Objective is to research and learn common patterns folks are using with AI to
> build."

<!-- What should be true when this is done? Write it however it comes out. -->

We want simply stated and concise pipelines in mermaid where they can be read and understood in 5 minutes or less.

Now I expect we will end up with many pipelines defined.

Outcome of a pipeline.md file would be:

```
# <Pipeline Name>

...mermaid
<mermaid diagram here>
...


## Pipeline Details

...
<pipeline details here>
...

## Supporting Skills 

### Outline

- `<skill-name>` : one line simple and concise description.

## Details

...
<Skill in depth details here>>
...
```

We will end up with one pipeline per discovered pipeline we find. We will iteratively and repetively search for pipelines in the wild with some validation proof (long commit history, lots of stars, lots of contributors, lots of references, authors provenance in the game dev community, surrounding signals etc).
