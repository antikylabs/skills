mapping-table assertion then counted decision-edge rows as node rows. I changed the checks to scan

nine chart nodes and nine linked mapping rows on every page.

The prose proxy flagged `seam continuity`. The phrase was literal, but “route closure continuity”
names the measured mechanism more precisely, so I rewrote it instead of suppressing the warning.

The first pinned link-check run tried to reach the npm registry inside the restricted sandbox and
failed DNS resolution. The same command passed with the approved network boundary; this was an
execution-environment failure, not a broken citation.
